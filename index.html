サービス分類別の件数(直近 日)

手元にある記事の件数です。記事が複数の分類に入るときは、それぞれで数えます。分類名を選ぶと、「記事」タブにその分類の記事を表示します。

    サービス分類ごとの週別の記事数(直近 日)

    週は月曜始まり(JST)で、グラフの横軸のラベルはその週の月曜日です。記事が 0 件の週も含めます。縦軸は分類ごとに最大値に合わせています。記事が複数の分類に入るときは、それぞれで数えます。見出しの分類名を選ぶと、「記事」タブにその分類の記事を表示します。

    グラフの表示には JavaScript が必要です。
